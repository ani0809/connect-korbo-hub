MyShop REST API v1

Base URL: /api/v1 · Auth: Bearer token (Laravel Sanctum) · JSON responses

Authentication

  • POST /auth/login — email or phone + password
  • POST /auth/register
  • POST /auth/logout (auth)
  • GET /auth/user (auth)
  • PUT /auth/profile (auth)
  • POST /auth/change-password (auth)
  • POST /auth/refresh-token (auth)
  • POST /auth/forgot-password, POST /auth/verify-otp, POST /auth/social-login

Catalog

  • GET /products, GET /products/{slug}
  • GET /products/{id}/reviews, GET /products/{id}/qna
  • GET /categories, GET /categories/{slug}
  • GET /brands, GET /search, GET /search/suggestions
  • GET /home, GET /banners, GET /flash-deals
  • GET /sellers, GET /sellers/{slug}
  • GET /settings, /countries, /currencies, /languages

Cart & checkout

  • GET /cart, POST /cart/add, PUT /cart/update, DELETE /cart/remove/{itemId}, DELETE /cart/clear
  • POST /cart/coupon, DELETE /cart/coupon
  • POST /checkout/shipping-methods, POST /checkout/place-order, POST /checkout/payment-intent

Account

  • GET /orders, GET /orders/{number}, cancel / reorder / review
  • GET /wishlist, POST /wishlist/toggle, GET /wishlist/ids
  • GET|POST|PUT|DELETE /addresses, default address
  • GET /wallet, GET /wallet/transactions
  • GET /points, GET /points/history
  • GET /notifications, mark read
  • GET|POST /support, replies
  • POST /reviews, POST /qna/questions, POST /qna/answers
  • GET|POST /compare, GET /downloads, GET /downloads/{id}/link
  • POST /fcm/register, DELETE /fcm/unregister

Success response

{
  "success": true,
  "message": "Success",
  "data": { },
  "meta": { "current_page": 1, "per_page": 20, "total": 100, "last_page": 5, "has_more": false }
}

Error response

{
  "success": false,
  "message": "Error description",
  "errors": { "field": ["validation error"] },
  "code": 422
}
